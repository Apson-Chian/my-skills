glass-ui

从卡片到浮动导航，统一透明度、背景模糊、高光与阴影。示例采用 CSS 背景模糊，底部展示分层渐进模糊近似。

使用 $glass-ui 改进当前界面的玻璃材质。
02 / INTERACTION阅读 SKILL.md ↗

liquid-glass-controls

让按钮、透镜和导航回应触碰。示例用同一背景画布提供折射输入，支持轻微色散、独立模糊、按压与拖动导航。

使用 $liquid-glass-controls 实现液态玻璃导航。
