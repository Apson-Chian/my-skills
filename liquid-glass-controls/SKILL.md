# 液态玻璃控件

把用户确认的通透材质与柔软压感接入当前网页。先看现有背景来源、控件与状态管理，沿用项目的布局、交互和样式体系。

## 当前默认基准

2026-11-13，用户要求用「Liquid Glass · 触见流光」本次实现替换旧基准，并明确确认没有手动改过滑杆：**通透材质、折射 72%、背景模糊 8%、压感 80%**。玻璃效果开启，其他背景与主题沿用目标项目。这是个人 Web 默认起点，新的明确要求优先。

- 玻璃中央能看见真实背景，圆角边缘产生实际位移。薄亮边与轻阴影建立厚度。
- 边缘带一点彩色折光；按住稍强，松手恢复。色彩局限于窄边缘，不做浓重彩虹描边或整面染色。
- 模糊独立于折射、压感调节，从清晰到柔雾；文字、图标、焦点独立绘制并保持清楚。
- 按下即时反馈，玻璃装饰面略展宽、压扁，折射增强；命中区域保持稳定。减少动态效果时保留静态状态反馈。

具体数值、单位、shader 与弹簧映射见 [当前材质参数](references/material-preset.md)。复用 WebGL、模糊缓存或拖动导航时读取 [实现接线](references/webgl.md)。

## 导航与控件行为

- 玻璃分段导航支持按住左右拖动。选中块连续 1:1 跟手，越过栏目中线即切换栏目，松手后弹簧贴合。保留在选中块上的抓取偏移，动画途中再次抓取从当前画面值接手。
- 使用 Pointer Events、`setPointerCapture` 与合适的 `touch-action`，拖出导航后释放仍能收尾。取消、失焦、页面隐藏或窗口变化时清理按压，恢复手势开始的栏目。指针手势完成后抑制随后的重复 click，保留原生键盘与辅助技术点击。
- 保留轻点、方向键、Home / End、空格和 Enter 选择。项目原有键盘模式优先，不为玻璃效果改变业务语义。
- 滑杆按住时滑块展宽、实色淡出，真实轨道从下方透出。位置持续跟手，释放、取消和失焦后复原。当前参考滑杆为 2D 轨道弯曲近似，不能称为 WebGL 折射。
- 按钮、滑杆、开关、导航共享折射、模糊、压感和效果开关状态。关闭效果后停止光学绘制，控件仍可操作。

## 渲染与复用

- 已有场景纹理、画布或可靠背景源时，让它同时提供可见背景和折射输入，采样位置随滚动、移动、场景更新与尺寸变化同步。
- 无法可靠采到普通 DOM 背景时用 CSS 通透磨砂回退，并说明没有实际背景位移。不能用静态复制图、整体缩放或模糊代替真实折射的验证。
- 背景源 → 材质效果 → 清晰前景，捕获时排除效果自身，避免递归取样。按需重绘，不循环 CPU 截图，不让静态场景持续刷新。
- 当前自包含参考为 [assets/atelier/index.html](assets/atelier/index.html)。从该目录启动静态 HTTP 服务即可预览；通常只移植所需 renderer、状态和交互，不复制演示布局、文案或照片到用户产品。
- 旧 `liquid-glass-js` 示例仅供维护旧接线或用户明确要求复现旧图时参考，见 [旧实现](references/legacy-webgl.md)。旧默认值不再作为当前起点。

## 验证

- 同一背景和坐标比较折射、模糊和静止 / 按压。确认真实纹理有位移，轻微色散主要在窄边缘，中央不被整面染色，文字与图标清楚。
- 拖动导航时检查跨栏、反向拖动、抓取偏移、松手吸附、拖出释放、触摸取消和键盘；检查窄屏、减少动态及效果关闭状态。
- 切场景、resize、关闭再恢复效果后，背景缓存与坐标仍正确；静止后停止绘制。
- 如实报告渲染路径与验证环境。当前参考通过 Chrome 桌面、390px 触摸模拟、320px 布局及回退检查；没有真实 iPhone / Safari 的验证结论。
