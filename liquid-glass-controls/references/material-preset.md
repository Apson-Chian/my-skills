## 默认值与单位

| 项目 | 默认 / 映射 |
| --- | --- |
| 材质 | 通透 `clear`，效果开启 |
| 折射 | 72%，归一化 `s = 0.72` |
| 背景模糊 | 8%，`radius = 0.11 × percent` CSS px，即 **0.88 px** |
| 压感 | 80%，归一化幅度 `a = 0.80` |
| 通透白色色调混合 | `0.045`，只作用于背景材质 |
| 柔雾预设 | 模糊 62%（6.82 CSS px）、白色混合 `0.25` |
| 模糊范围 | 0–100%，对应 0–11 CSS px；与折射和压感独立 |
| 光照 | 左上，法线方向 `normalize(-0.65, -0.8)` |

百分比是本实现的 UI 刻度，不等于 CSS opacity 或 blur px。迁移到其他 shader / 平台时按视觉与真实位移调校，不能照搬旧库参数名冒充相同效果。

## 光学参数

`q` 为按压弹簧当前值（静止 0、按住目标 1），`p = q × a`，默认按住时 `p = 0.8`。`depth` 为圆角矩形内部到边界的 CSS px，`halfHeight` 为表面高度的一半，`normal` 是外法线，`localPoint` 是相对表面中心的位置。

```glsl
band = min(28.0, halfHeight * 0.55) * (1.0 + p * 0.32);
rim = 1.0 - smoothstep(0.0, band, depth);
bend = (-sin(rim * PI) * (15.0 + p * 34.0)
        + pow(rim, 9.0) * (6.0 + p * 10.0)) * s;
offset = normal * bend - localPoint * (0.018 + p * 0.038) * s;
```

中央仅有轻微放大，边缘位移随按压增强；DOM 前景不进入折射源。

**轻微色散**：红、蓝通道在折射后的采样点两侧微移，绿色保持基准采样。色差距离如下，最大 1.5 CSS px，只在边缘明显：

```glsl
chroma = pow(rim, 3.0) * min(1.5, (0.35 + p * 1.45) * s);
```

另在约 0.8–5 CSS px 深度加入很淡的珠光，2 CSS px 附近最明显：

```glsl
spectralBand = smoothstep(0.8, 2.0, depth)
             * (1.0 - smoothstep(2.0, 5.0, depth));
phase = atan(normal.y, normal.x) * 1.3 + depth * 0.45;
spectrum = 0.5 + 0.5 * cos(phase + vec3(0.0, 2.0944, 4.1888));
sheen = spectralBand * (0.025 + p * 0.045) * s;
color = mix(color, spectrum * 0.65 + vec3(0.35), sheen);
```

默认 `s = 0.72` 时，珠光混合峰值静止约 **1.8%**，按住约 **4.4%**。保持薄、淡、局部；不要改成整面高饱和渐变，也不要降低整体 opacity 导致前景变淡。

按住时白色色调混合乘 `1 - p × 0.58`，背景更通透。清晰背景与平滑模糊缓存的混合使按住时清晰度增加；无模糊缓存的多点采样回退则将模糊半径乘 `1 - p × 0.48`。

## 压感与弹簧

| 参数 | 当前参考 |

| 透镜装饰面形变 | `scale(1 + 0.095 × p, 1 - 0.08 × p)` |

| 按压弹簧 | 质量 1、刚度 460、阻尼 35，`dt ≤ 0.032s` |
